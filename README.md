# 🐳 Docker + Grafana Monitoring

Projeto desenvolvido para praticar **Docker**, **Nginx**, **Prometheus** e **Grafana**, criando um ambiente simples de monitoramento de um container.

## 🎯 Objetivo

Criar um ambiente utilizando Docker Compose, com um servidor Nginx executando em container, Prometheus realizando a coleta de métricas e Grafana para visualização dos dados.

## 🛠️ Tecnologias

* 🐳 **Docker** — containerização e gerenciamento dos serviços
* 🌐 **Nginx** — servidor web executando em container
* 📊 **Prometheus** — coleta e armazenamento das métricas
* 📈 **Grafana** — visualização e monitoramento das métricas

## 🏗️ Arquitetura

```text
Docker Compose
│
├── Nginx
│
├── Prometheus
│
└── Grafana
```
